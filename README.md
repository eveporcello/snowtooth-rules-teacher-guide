# Snowtooth Rules: Teacher Guide

Facilitator materials for the Snowtooth Rules workshop. Students work in [snowtooth-rules](https://github.com/eveporcello/snowtooth-rules), which doesn't include any of these files. Keep it that way: if the notes are in the student repo, the agent reads them and gives away the answers.

| File | What it is |
| --- | --- |
| `plan.md` | Goals, timing, and what we're leaving out |
| `demo.md` | Minute-by-minute runbook for the facilitator |
| `handout.md` | Student steps. Paste it into chat during the session. |
| `snowtooth-rules.pptx` | The deck |

## Student repo branches

| Branch | What you get |
| --- | --- |
| `main` | Start here. One lift board. No project rules yet. |
| `checkpoint` | Mid-point. Data rule, trails panel, grooming report. |
| `complete` | Done. Copy rule and the Open Runs panel. |
